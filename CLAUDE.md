# SMard Web Crawler

Self-hosted scraping to Markdown through a multi-engine fallback chain, with a CLI,
HTTP API, MCP server and Claude Code plugin. Package: `smard_crawler` (pyproject.toml).

## Project Structure

```
smard-web-crawler/
├── pyproject.toml              # package, extras ([server,mcp,cloak,bench,direct,dev,all]), console scripts
├── docker-compose.yml          # obscura + crawl4ai + api (loopback ports, tokens required)
├── Dockerfile, docker/obscura/ # API image; Obscura stealth release image (sha256-pinned)
├── .env.example                # all settings; loaded from $SMARD_ENV_FILE, ./.env, ~/.smard-crawler/.env
├── smard_crawler/
│   ├── cli.py                  # smard-crawler scrape|batch|crawl|map|health|serve|mcp|bench
│   ├── common/
│   │   ├── config.py           # env-driven dataclasses (empty value = unset)
│   │   ├── scraper.py          # UnifiedScraper: ENGINE_ORDER chain, intra-retry, liveness, batch recheck
│   │   ├── robots.py           # RFC 9309 robots.txt guard (on by default)
│   │   ├── budget.py           # rate limit + daily cap for paid Decodo engines
│   │   ├── urlguard.py         # SSRF guard for API/MCP input
│   │   ├── markdown.py         # HTML -> Markdown for browser engines
│   │   └── stealth.py          # profiles, GREASE sec-ch-ua, navigator init script
│   ├── browsers/client.py      # ObscuraClient (CDP, spawns OBSCURA_BIN on demand), CloakBrowserClient
│   ├── crawl4ai/client.py      # Crawl4AI 0.9.x typed-config API (untrusted-field allowlist!)
│   ├── firecrawl/client.py     # Firecrawl v1 API

│   ├── server/                 # api.py (FastAPI), mcp_server.py (MCPServer, stdio), service.py
```

## Fallback Architecture

```
Request → robots.txt check → ENGINE_ORDER (skip unavailable):
  [1] obscura       self-hosted, stealth TLS, free
  [1] crawl4ai      self-hosted Chromium, free
  [1] firecrawl     self-hosted stack, free  (preferred for crawl)
  [1] cloakbrowser  local stealth Chromium, free tier = 1 session
  [2] site_unblocker  Decodo, paid  ┐ PaidGuard: DECODO_MAX_RPS + DECODO_DAILY_LIMIT
  [3] web_data_api    Decodo, paid  ┘
```

`crawl()`: Firecrawl (preferred) → native BFS over a browser engine (common/crawl.py,
same-site, robots-gated) → Web Data API. The native fallback keeps crawl working
without Firecrawl's service stack; Firecrawl stays first when it is up.

## Conventions

- Python 3.12+, async/await throughout, `httpx` for HTTP, `tenacity` for retry (retry only transport errors and 5xx)
- All config via environment variables, never hardcoded secrets; tokens are generated by the installers
- Pinned deps in `constraints.txt` (installers and Dockerfile apply it); regenerate with `pip freeze` in a fresh venv after a deliberate bump
- Type hints on all public APIs
- Output markdown files include YAML frontmatter metadata
- Proxy URL format: `http://user:pass@host:port`
- Health checks must never spend billed requests (Decodo health = configuration only)
- Tests: `pytest -q`; with `OBSCURA_BIN=<path>` the Obscura integration tests also run

## Engine-specific constraints (verified against real servers)

- **Crawl4AI 0.9.x**: needs `CRAWL4AI_API_TOKEN` or it binds container loopback only; set `GUNICORN_BIND=0.0.0.0:11235` (the default `[::]` bind fails without IPv6). Request bodies may not carry `proxy_config`, `magic`, `simulate_user`, `override_navigator`, `js_code`; timeouts are capped at 60s. Proxy goes via `CRAWL4AI_UPSTREAM_PROXY`.
- **Obscura**: use the `-stealth` release or the TLS fingerprint is not Chrome's. Ignores `HTTP(S)_PROXY`; pass `--proxy`. Non-loopback binds require `OBSCURA_CDP_TOKEN`. Blocks private networks unless `OBSCURA_ALLOW_PRIVATE_NETWORK=1`.
- **Firecrawl self-hosted**: a full upstream stack (API, workers, Playwright, Redis, RabbitMQ, Postgres), started by `scripts/firecrawl-up.sh` at a pinned tag.
- **Playwright `connect_over_cdp`**: never pass `headers={}`; omit the argument when there is no token.
